# 📰 News App

A responsive and modern **News Application** built using **HTML, CSS, and JavaScript** that fetches real-time news articles using the **NewsAPI**.

---

## 🚀 Features
- 🔍 Search news by keyword (e.g. Science, Technology, Sports)
- 🏏 Quick category filters (IPL, Finance, Politics)
- 📰 Real-time news fetched from NewsAPI
- 🖼️ Dynamic news cards with images, source, and publish date
- 📱 Fully responsive UI
- 🔗 Click on any news card to read the full article

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **NewsAPI**
